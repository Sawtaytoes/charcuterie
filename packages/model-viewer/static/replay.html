How to read the head model

  • The cone is the nozzle tip. It takes the color of the filament that is loaded.
  • The translucent cylinder is the slicer's clearance model (extruder_clearance_max_radius). It turns red when a printed part that is taller than the nozzle tip is inside it.
  • The bar across the bed is the X gantry (extruder_clearance_height_to_rod above the tip). A part taller than that must print last.
  • This is the slicer's collision model, not toolhead CAD.

What the checks read

  • Every move in the G-code, arcs included, with filament changes and purges.
  • Color, only when the plate names a split height: each part extrudes its bottom tool below the split and the top tool above it.
  • Collisions: the nozzle tip never goes below the top of a part that is already printed.
  • Clearance: no part taller than the nozzle tip is inside the clearance circle.
