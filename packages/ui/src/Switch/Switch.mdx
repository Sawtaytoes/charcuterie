# Switch

A boolean that takes effect the moment it is flipped — a setting, not a form value.

A `Switch` and a [`Checkbox`](/docs/components-checkbox--docs) are the **same state kind and
a different affordance**, and the split is meaning rather than looks. A checkbox is a value
you submit — "delete originals", "I agree". A switch is a state you toggle and live with
immediately — "automatic imports on". ARIA gives the second its own role, and a screen
reader announces "on/off" for a `switch` where it announces "checked/unchecked" for a
checkbox.

## A `button role="switch"`, not an `input`

The sliding track and thumb are the whole affordance, and a `<button>` styles them without
fighting a native control's own rendering. It carries `aria-checked` and `aria-labelledby`
and nothing else the browser would try to own, so its keyboard path is the button's: Tab
reaches it, Space and Enter flip it.

The value lives in React state seeded once from `isChecked` — the switch is the store, the
same way the DOM is for `Checkbox`, and the same refusal of a controlled prop.

## The thumb changes colour, not just position

On `bg-intent-accent-solid`, off on `bg-surface-sunken`, and the thumb picks the token that
contrasts with whichever it is sitting on. A switch whose only signal was the thumb's
*position* loses that signal to a `daylight` theme in sunlight or to a colour-blind reader;
a filled track plus a contrasting thumb survives both, which is the same reason
`SegmentedControl` fills its checked option rather than tinting it.

## Disabled dims, read-only does not

`isDisabled` removes the switch from the tab order and the pointer and turns the whole
control down with `opacity-60` — a setting the user cannot currently change, a policy
forced from above, still fully visible. `isReadOnly` is the other half: full contrast so
the state stays legible, but the accent gives way to the **neutral** intent and the flip
is refused (`aria-readonly`, the `onClick` guarded). A read-only switch is a value you may
read here and change elsewhere; a disabled one is a control that is simply off-limits now.
