Scheme switcher — design preview

Two candidate presentations for the 3-mode (light / dark / system) scheme control, each rendered with charcuterie's real @charcuterie/tokens palette, in both data-scheme="light" and data-scheme="dark". Icons are hand-drawn inline SVGs in the icons.storyHelpers.tsx style — the library ships no icons (ship-no-icons decision); a consuming app would pass lucide Sun/Moon/Monitor. This is a proposal mock, not the shipping component.

Form A — cycling single button (the owner's description)

One button. It shows the icon for the current mode and cycles light → dark → system → light on click. Accessible name announces the current mode and the next one, so getByRole("button", { name: /scheme/i }) resolves. Built on IconButton.

data-scheme = light
Click it — this panel stays light; the button state cycles.
mode: light
data-scheme = dark
Same control on the dark surface.
mode: dark

Form B — all-three-visible SegmentedControl

All three modes on screen as a radiogroup (charcuterie's SegmentedControl). Arrow keys move + select; the checked option is the current mode. No hidden state — the tradeoff is horizontal space.

data-scheme = light
